Three passes, in order

Every PR gets the first two. The third depends on what the PR touches, not on who wrote it.

  1. 1

    Copilot auto review

    Every PR, every push · seconds

    Fast line comments with fixes you can apply in one click.

    • Bugs and unhandled edge cases
    • Security slips
    • Broken contracts and weakened tests
  2. 2

    Agent review

    Every ready PR, every push · minutes

    A different AI runs a five-axis review, using Addy Osmani's code-review skill, and reports only what it can prove.

    • Correctness, readability, architecture, security, performance
    • Blast radius: who still calls what changed
    • Can only escalate, never approve
  3. 3

    Deep review

    Only high blast radius · 30–60 minutes

    The code owner and a second reviewer spend their time where it pays.

    • Verify the tests would catch a regression
    • Check constraints and every changed contract
    • Make sure it can be rolled back

Light PRs still get a human approval: a 5-minute check after both AI reviews are clean. The review-gate status won't pass until the agent review is clean on the latest commit.
